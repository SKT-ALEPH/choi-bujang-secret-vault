## XDR에서 만든 범위

| 모듈 | 구현과 실제 연결 | 당시 판정 |
| --- | --- | --- |
| XDR-01 무차별 로그인 | 가상 Wazuh 경보 분석, 규칙·실제 Jev 보조 판단, 신뢰 주소별 실패 합산, Supabase 경보·거부 저장, 15분 만료, 실제 Auth429·Notes403 | 100/100 |
| XDR-02 웹 입력 조작 | SQL·스크립트·경로 이탈·명령 삽입 문법 신호, 반복 합산·실제 Jev, Supabase 경보·거부 저장, 두 guard 합성, 실제 Auth429·Notes403 | 100/100 |

- 무차별 로그인: 실제 실패 20건 후 21번째 요청 거부, 위조 출발 헤더 우회 거부, 로그인된 메모 요청 차단과 복귀를 확인했다.
- 웹 입력 조작: 운영 DB의 120초 고정 집계 창에서 명확한 신호 8회 합산으로 차단했다. 실제 8번째 요청 429, Retry-After 900초, Jev 실제 응답 7건을 확인했다.
- 가상 경보 재생 결과는 XDR-01 block10/alert9/record9, XDR-02 block8/alert9/record9이며 실제 모델 응답 결과와 구분한다.
- 차단 근거는 경보 UUID, 상태는 서버 전용 DB에 저장한다. 원문 IP·계정은 HMAC 처리하며 비밀번호·JWT·메모 본문을 AI나 경보 로그에 보내지 않는다.
- 복귀 검증은 자신이 만든 시험 규칙의 만료를 앞당긴 방식이었다. 실제 15분을 기다린 시험으로 기록하지 않는다. TTL 900초와 만료 경계는 별도 확인했다.
- 기존 토큰 검증, 소유자 검사, 로그아웃, 기본 starter.deny는 유지했다.

## 완성하지 않은 범위와 확인 제한

실시간 Wazuh 수집기, 운영 반 공용 ZTNA 엔진 설치, PC 방화벽 설치, 다른 XDR 모듈 및 최종 ZTNA·XDR 제품 패키지는 이 완료 범위에 포함하지 않는다. 웹 감지기는 모든 웹 경로·취약점을 막는 전역 WAF가 아니다.

일반 B 계정의 브라우저 로그인 시험은 수행하지 않았으며 DB 역할 시험과 심판 검증으로 구분한다. 두 설명 Page의 본문 저장과 Mermaid 문법은 확인했지만 실제 Page 렌더 화면은 미확인이다. 웹 입력 문서의 임시 작업 기록은 해당 화면 확인이 남아 있어 보존 중이다.

## 보관한 원본과 근거

- sources/project-context.md: 보관 직전 루트 AGENTS.md의 바이트 그대로인 전체 이력. 초기 미완료 기록과 이후 완료 기록이 함께 있으므로 날짜와 최종 완료 절을 구분한다.
- sources/repository-rules.md: 저장소 AGENTS.md 원본. 보관 파일은 현재 실행 지시가 아닌 역사 자료다.
- sources/implementation-readme.md: 당시 구성·실행·검증 설명 원본.
- sources/XDR_RULES.md와 XDR_WEB_INJECTION_RULES.md: 당시 영구 제약과 실패 분류.
- sources/XDR_OPERATOR_CONNECTION.md: 당시 서버 연결 설명 원본.
- evidence/: 두 XDR 심판 결과와 최종 배포 점검 JSON 4개. 2차 단계별 화면, HTTP 상세, DB 화면 등 추가 근거는 기존 artifacts 폴더에 남아 있으며 이 묶음에는 복제하지 않았다.
- MANIFEST.sha256: 이 폴더의 문서와 근거 파일별 무결성 확인값.

코드 원본은 이 묶음에 복제하지 않았으며 위 고정 Git 커밋을 기준으로 조회한다. 원본 문서를 하위 폴더로 복사했으므로 그 안의 상대 링크는 보관 이전 위치를 기준으로 해석해야 한다.

## 보존 방식

이 날짜 폴더는 일반 진행 상황 갱신으로 덮어쓰거나 임시 문서 정리 때 삭제하지 않는다. 이후 상태는 새로운 날짜의 고정본으로 추가한다. 사실 오류는 날짜가 있는 정정 기록으로 연결하고 비밀값 발견 시 즉시 가린 뒤 안전한 정정 이력을 남긴다.

파일 읽기 전용 권한과 SHA-256 확인값은 실수 방지 및 변경 감지 수단이며 수정 불가능한 저장장치의 보장은 아니다. 이 고정본과 같은 이름의 tar.gz 및 sha256 파일을 상위 history 폴더에 보관한다. 현재는 로컬 작업 폴더에 저장했으며 외부 백업·원격 push를 수행한 것은 아니다.
