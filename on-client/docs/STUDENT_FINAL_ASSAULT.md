### 다듬을 핵심 기능3개와 우선순위

1. **PC 자원 상태**: CPU 사용률·메모리 사용량·디스크 여유와 측정 시각/단위를 확인한다. 제공 기능이 준비되면 재사용하고, 학생 개선으로 최근 측정 변화 비교를 우선 검토한다. 조회 실패에0이나 가짜 값을 넣지 않는다.
2. **네트워크·방화벽 현황**: 연결 구성과 읽을 수 있는 방화벽 설정을 조회한다. SDP 연결은 별도 표시한다. 관리자 권한이나 보안 설정 변경을 사용하지 않는다.
3. **Windows 기록 조회**: System/Application의 최근 경고·오류 건수를 기간·조회 시각과 함께 보여 준다. 이 건수를 공격 탐지나 침해 판정으로 표현하지 않는다.

기존 접속 판정·보안 기록·AI 표시 기능은 보존한다. 이 목록은 앞으로 구현할 우선순위이며 현재 구현 완료 목록이 아니다.

### 다시 실행하는 방법

Node24.19.0을 사용할 수 있는 터미널에서 기존 `on-client` 폴더로 이동한다.

```sh
node --version
node src/server.mjs
```

http://127.0.0.1:5189/ 에서 보호 현황 → 다시 불러오기 → 업무 앱 → 보안 기록을 확인한다. 기본 모드의 정상 기대 결과는 연결 정보가 준비되지 않았다는 오류 안내다. 데이터가 없는데 접속 허용·정상 신원·안전으로 표시되면 안 된다.

이번 서버를 Ctrl+C로 종료하고, 같은 폴더에서 `node src/server.mjs --demo`로 실행하면 예제 상태를 비교할 수 있다. demo의 세 앱 요청과 event-01 상세가 표시되어도 운영 연결이 된 것은 아니다. Windows의 공식 실행 방법은 [학생 실행 설명서](STUDENT_RUNBOOK.md)를 따른다.
