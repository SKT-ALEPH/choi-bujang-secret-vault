# 케셰브 · PC 대시보드 실행 안내 한 장

내 PC의 자원과 연결 구성을 읽고, Windows에서는 방화벽 프로필·최근24시간 기록 건수까지 확인하는 **학생 개발 앱**이다. 자료실·SDP 서버의 접속 판정과 별도이며, 실행만으로 보호/침해 여부를 판단하지 않는다. 승인된 설치형 패키지는 아직 준비되지 않았다. setup.exe는 이번 작업에서 제외했다.

## 1. 실행 준비

- 받은 프로젝트의 `on-client` 폴더를 연다. `student/start-daily.mjs`, `student/extension.mjs`, `src/server.mjs`, `public/index.html`이 있어야 한다. 기존 파일은 덮어쓰지 않고 새 경로에서 시작해도 된다.
- [공식 Node.js24.19.0](https://nodejs.org/dist/v24.19.0/)을 OS/CPU에 맞게 준비한다. 터미널에서 `node --version` 결과가 `v24.19.0`인지 확인한다. 다른 버전이면 이 실행의 검증 범위와 다르다. 전역 버전을 바꿀 필요 없이 공식 portable Node의 전체 경로로 실행해도 된다.
- 이 개발 실행은 Node 기본 기능만 쓰므로 추가 npm 설치·API 키·OAuth 로그인·관리자 권한이 필요 없다. Windows PowerShell로 앱을 시작해도 관리자 모드는 사용하지 않는다.

## 2. 앱 켜기

터미널의 현재 폴더가 `on-client`일 때:

```sh
node student/start-daily.mjs
```

터미널을 켜 둔 채 브라우저에서 **http://127.0.0.1:5189/** 를 연다. 종료는 같은 터미널의 Ctrl+C다. 포트가 이미 사용 중이면 다른 프로그램을 종료하지 말고 다음처럼 빈 포트를 선택한다.

macOS/Linux:
```sh
ON_PORT=5196 node student/start-daily.mjs
```

Windows PowerShell:
```powershell
$env:ON_PORT='5196'
node student/start-daily.mjs
```

이 경우 http://127.0.0.1:5196/ 을 연다. `localhost` 대신 안내의 `127.0.0.1` 주소를 사용한다.

## 3. 화면에서 확인

1. **보호 현황 → 내 PC 상태 다시 조회**: CPU%·메모리GiB·디스크GiB와 측정 시각/출처를 확인한다. 한 번 더 누르면 직전 성공 측정과 차이가 나온다. CPU는250ms 평균, 메모리는전체−여유, 디스크는홈파일시스템 가용공간이다.
2. **연결과 기록 다시 조회**: 네트워크 구성, Windows 방화벽 세 프로필, System/Application의24시간 경고/오류를 확인한다. Mac/Linux의 Windows 항목은 확인 불가가 정상이다. 기록 건수는 공격 탐지가 아니다.
3. **SDP 서버**: 서버 연결 관측이 없어 확인 불가가 정상이다. 상단 연결 없음과 계정·업무 앱·기존 보안 기록 오류는 PC 조회 성공과 별도다. 기존 상세는 펼쳐 볼 수 있다.

자동 조회·자동 외부 전송은 없다. Tab/Shift+Tab으로 이동하고 Enter/Space로 버튼·펼치기를 사용할 수 있다.

## 4. 막혔을 때

| 보이는 현상 | 다음 행동 |
|---|---|
| 학생 개발 실행기가 필요함 | 기존 제공 실행기 대신 위의 `student/start-daily.mjs`로 시작하고 앱 주소를 새로고침한다 |
| 로컬 조회 세션 확인 불가 | 지금 앱 주소를 새로고침한 뒤 버튼으로 다시 조회한다 |
| 다른 조회 진행 중 | 완료된 뒤 다시 조회한다. 자동 재시도하지 않는다 |
| 항목 확인 불가·시간 초과 | 실패한 항목과 이유를 확인하고 직접 다시 조회한다. 관리자 권한·보안 설정 변경·가짜 값 대체를 하지 않는다 |
| 첫 화면이 안 열림 | 터미널의 첫 오류, Node버전, 현재폴더, 선택한포트를 확인한다. 비밀번호/키/전체로그는 공유하지 않는다 |

다른 폴더에서 재현한 실제 결과와 한계는 [일차별 작업 기록](STUDENT_FINAL_ASSAULT.md)에 있다. 이 안내는 개발 소스 실행 안내이며 `INSTALL.md`나 공식 설치 검증을 대신하지 않는다.
