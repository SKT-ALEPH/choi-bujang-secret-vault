# 개인 AI 화면

기존 Keshev MASTER.md의 Soft UI Evolution·색상·서체·접근성 기준을 따른다. plain HTML/CSS/DOM이며 새로운 UI 프레임워크를 추가하지 않는다.

- 개인 모드의 AI 도우미는 독립된 메뉴/tabpanel이다. 기본 제공 탐색기가 키보드 선택과 ARIA를 함께 관리한다. 보호 현황·업무 앱·보안 기록에 AI 입력을 반복해서 끼워 넣지 않는다.
- 기본 화면은 간단한 목적과 연결 배지, 입력/설명 두 패널로 구성한다. 1100px 이하에서 입력→설명 순서의 한 열로 전환한다.
- 주요 행동은 AI 설명받기 하나다. 모델 조회는 보조 버튼, 계정·로그아웃·연결 점검은 native details 설정에 둔다. 취소는 요청 중에만 보여 준다.
- 개인정보인 계정 이메일은 펼친 설정 안에만 표시한다. 상단은 ChatGPT 연결 상태와 보안 서버 상태를 따로 설명한다. 미연결 보안 서버를 AI 연결 완료로 바꾸지 않는다.
- 예시 데이터는 사용자 버튼으로 입력하고 자동 전송하지 않는다. 글자 수, 전송 대상과 주의 정보를 입력 근처에 둔다.
- 설명은 문단/목록/강조만 DOM으로 구성한다. HTML·스크립트·이벤트를 해석하지 않고 원문 텍스트로 보존한다. 모델과 확인 시각은 결과 하단의 별도 메타데이터다.
- 대기/로딩/오류/취소/완료를 텍스트로 구분한다. 모델 목록을 AI 설명 성공으로 표시하지 않는다. 연결 변경·모델 변경·취소 시 이전 결과를 폐기한다.
- 저장·인증·SDK·Origin 검사와 기존 과제 함수는 수정하지 않는다. 실제 동작 검증과 대역 시험을 구분한다.

스킬 검색에서 첫 progressive disclosure 검색은 관련 없는 Heading Line Balance가 나와 적용하지 않았다. 좁힌 primary/secondary buttons 검색의 Loading Buttons는 중복 제출 방지에 적용했다. 배치와 설정 접기는 quick-reference의 primary-action/content-priority/visual-hierarchy 원칙 및 현재 화면 관찰을 근거로 결정했다.
