# 자료실 배치 · 2026-10-20

MASTER의 색상·서체·기본 컴포넌트를 유지하며, 자료실 화면에서는 이 배치 규칙을 우선한다.

## 사용자 목표

먼저 로그인과 기기 확인을 완료하고, 내 메모를 읽고 이어 작성한다. 사용 절차와 검사 기록은 필요한 때 확인한다.

## 로그인 전과 기기 확인

- 상단: 브랜드 / 이용 안내 / 검사 기록. 상태 알림은 두 화면에서 항상 노출되는 별도 영역에 둔다.
- 데스크톱: 왼쪽에 간결한 소개와 3단계 순서, 오른쪽에 로그인 또는 기기 확인 카드를 둔다. 큰 영문 소개와 설치 설명이 로그인보다 먼저 화면을 차지하지 않는다.
- 1280×720에서 로그인 제출 버튼이 초기 화면 안에 들어온다. 모바일은 소개를 줄이고 단일 열로 전환한다. 실습용 가상 자료 안내는 모바일에서도 보인다.
- 실제 로그인/기기 승인/복구 상태는 기존 컨트롤러가 `hidden`으로 결정한다. CSS는 그 상태에 맞춰 배치만 조정한다. CSS로 보안 승인을 만들지 않는다.
- 비밀번호 복구에서 로그인 카드가 표시되면 기기 확인 카드는 시각적으로 겹치지 않는다. `status`와 `auth-error`의 실시간 안내는 유지한다. 기존 세션의 로그아웃 버튼은 별도로 보존하며, 복구 상태에서도 사용할 수 있다.

## 승인 후 작업

- 로그인용 소개를 접고 `내 메모` 제목과 작업 화면을 먼저 보여준다.
- 큰 화면: 메모 목록 왼쪽 / 작성·편집기 오른쪽. 목록을 확인하려고 편집기를 지나 아래로 내려가지 않는다.
- 태블릿/모바일: 목록 다음에 편집기를 두고, 상단 `메모 작성으로 이동` 링크가 제목 입력칸으로 초점을 옮긴다.
- 기존 수정·삭제·로그아웃·수동 새로고침·편집 취소·Ctrl/⌘+Enter 저장을 유지한다. 빈 목록 안내는 `위` 같은 방향 대신 `메모 작성 영역`을 가리킨다.

## 보조 정보

- 이용 안내와 보안 검사 기록은 각각 native details로 접어 둔다.
- 상단 링크는 접힌 본문 안의 제목을 가리켜 브라우저가 해당 details를 펼치고 이동한다. 별도 네비게이션 스크립트를 추가하지 않는다.
- 45행 검사표와 근거·실패·미실행 설명을 보존한다. 전체 페이지가 길어지지 않도록 표 영역 안에서 스크롤한다. 표의 좁은 열에서 ID가 조각나지 않도록 최소 너비를 확보한다.
- 기록은 서버의 저장된 결과이며 새 보안 시험/운영 엔진 실측으로 바꾸어 표현하지 않는다.

## 적용 위치와 검증 범위

- `public/index.html`: 원래 제어 ID·보안 hidden·ARIA·폼·스크립트를 보존한 재배치.
- `on-client/public/style.css`: `.vault-workspace-layout` 및 자료실 전용 클래스. `public/style.css`와 오프라인 내장은 기존 빌드로 동기화한다.
- `public/app.js`: 빈 목록 안내 문장만 변경, 인증·기기·자료 요청 로직은 동일하다.
- 자동 검사: controller ID/초기 노출 금지/라벨 연결/공통 테마/기존 기기·PWA·자료 처리 시험.
- 실제 미로그인 UI와 별도의 명시적 배치 예시(기기 확인·메모·빈 목록·복구)로 반응형을 확인한다. 예시를 실제 계정 로그인·CRUD 검증으로 표시하지 않는다. 예시 서버와 자료는 운영 배포에 포함하지 않는다.
