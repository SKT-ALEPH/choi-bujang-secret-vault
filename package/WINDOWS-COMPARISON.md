# Windows 실측과 기본 도구 대조

2026-10-27 등록된 Parallels Windows11의 실제 통합 앱과 Windows 작업 관리자를 직접 열어 확인했다. 예제 화면이나 명령 출력만으로 작업 관리자 확인을 대신하지 않았다.

| 항목 | 실제 기본 도구 | 실제 앱 | 해석 |
|---|---|---|---|
| CPU | 13:17:08 KST 화면14% | 13:17:09, 2.88%, node:os.cpus 전체 논리 CPU의250ms 구간 평균 | 1초 갱신 작업 관리자의 utility와 앱의 짧은 CPU 시간 표본이 다르다. 요청 시작과 다른 수집 작업의 부하도 포함돼 정확히 같은 값이라고 하지 않는다 |
| 메모리 | 같은 화면4.3/8.0GB | 13:17:08,4.28GiB, OS 전체−여유 | 작업 관리자 표시 반올림과 가까운 집계. 다른 시각의 변화와 캐시·압축 차이를 동일 값으로 강제하지 않는다 |
| 디스크 가용 | 13:31~13:32 탐색기 C:254GB 중224GB 사용 가능 | 13:32:26,224.56GiB, 사용자 홈 파일시스템 statfs | 탐색기 반올림과 비교. 작업 관리자의 디스크0%는 활동 시간이라 가용 공간과 비교하지 않는다 |

처음 CPU 조회는 PowerShell 연결/이벤트 수집을 동시에 시작해80%대 표본을 만들었다. `netbird-vault.mjs`에서 CPU를 먼저 측정하고 이후 무거운 수집을 시작하도록 수정했다. 수정 후에도 실제 활동·짧은 표본·프로세스 시작 비용은 남으므로2.88%나14%를 고정 기대값으로 만들지 않는다. UI는 시각·출처·단위·이전 성공 표본의 변화와 실패를 표시한다.

검증 기록은 작업 폴더의 `artifacts/final-submission-2026-10-27/windows-task-manager-comparison.json`, `windows-disk-comparison.json`에 보관한다. 실제 작업 관리자 캡처 중 메일 자동완성/다른 창이 포함될 수 있는 화면은 공개 저장소에 넣지 않았다. 이 비교는 성능 관측이며 공격 탐지/전체 PC 안전의 증명이 아니다.
